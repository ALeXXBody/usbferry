Share USB & LAN over the internet

usbferry has two roles. The server machine shares its USB devices and network. The client machine uses them as if they were plugged in locally. This app can do either — or both at once.

🖥️ Use another machine's USB/LAN
Add a remote usbferry server and connect to it. Attach its USB devices, join its LAN.
⌨️ Share THIS machine's USB/LAN
Run the usbferry server here. Other machines connect to this PC and use its USB devices over the internet.
